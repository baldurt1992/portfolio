## De una necesidad de negocio a un producto funcionando

Soy **Andrés Baldur Tamayo Marín**, ingeniero de software full stack en Colombia. Colaboro de forma remota con empresas, agencias y equipos de Europa y Latinoamérica que necesitan lanzar un producto, evolucionar una plataforma existente o convertir una operación manual en software mantenible.

Mi stack principal es **Laravel + Vue/Nuxt**. También desarrollo soluciones WordPress a medida cuando un CMS, WooCommerce o un ecosistema de plugins es la decisión correcta para el negocio.

Puedo hacerme cargo del ciclo completo:

- **Descubrimiento y producto:** convierto procesos, reglas y objetivos comerciales en flujos claros y entregables.
- **UX y frontend:** construyo interfaces responsivas, accesibles y enfocadas en que el usuario complete la acción importante.
- **Backend y arquitectura:** modelo datos, APIs, permisos, jobs, integraciones y entornos multi-tenant.
- **Entrega a producción:** preparo contenedores, CI/CD y despliegues para que el producto no termine detenido en una demo.

## Este repositorio también es una muestra técnica

El sitio no solo enseña el resultado: su código demuestra cómo estructuro y publico una aplicación moderna.

- **Frontend:** Nuxt 4, Vue 3, TypeScript, Tailwind CSS 4 y Nuxt UI.
- **Experiencia:** i18n español/inglés, diseño responsive, GSAP con soporte para `prefers-reduced-motion` y una escena ambiental con Three.js.
- **SEO y descubrimiento:** metadatos localizados, rutas prerenderizadas, sitemap y `robots.txt`.
- **Integraciones:** formulario con EmailJS y verificación anti-spam mediante Cloudflare Turnstile.
- **Entrega:** CI con GitHub Actions y despliegue automatizado de `main` en Hostinger.
- **Calidad:** ESLint, comprobación de tipos con Nuxt y smoke tests con Playwright.

## Ejecutarlo en local

Requiere **Node.js 22**.

```bash
npm ci
npm run dev
```

Comprobaciones disponibles:

```bash
npm run lint
npm run typecheck
npm run test:e2e
npm run build
```
